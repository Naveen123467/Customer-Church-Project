# Customer-Church-Project
Analyze customer churn behavior using Python and Power BI. This project includes data cleaning, exploratory analysis, and building interactive dashboards to identify key churn drivers and support customer retention strategies.
## Project Overview
This project focuses on analyzing church data to understand **donation trends, attendance, and member engagement**. 

## Tools Used
- **Python (Jupyter Notebook)** – Data cleaning, preprocessing, and visualization
- **CSV** – Data source

## Project Workflow
1. **Data Cleaning**
   - Removed duplicates and missing values
   - Standardized dates and categorical fields
2. **Data Visualization**
   - Generated graphs for donations, attendance, and engagement metrics
3. **Dashboard (Conceptual)**
   - Designed an interactive Power BI dashboard for tracking key metrics (no actual dashboard file required)
